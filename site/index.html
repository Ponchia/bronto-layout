The rule behind the result

Make the intention explicit.

Keep these two top edges within 2 CSS pixels, from 768px upwards. That is the alignment rule used for both captures—not a visual guess made after the check.

The names paragraph and image refer to selectors in the full contract. At smaller widths the content stacks, so this particular rule is skipped.

02 / From install to a useful result

Start with a known outcome.

Run these in your Node.js project. The published package includes both fixtures and their contract. No source checkout or build required.

  1. Install, then check the browser

    This example pins the qualified npm version. @beta follows the current beta tag.

    npm install --save-dev @ponchia/layout@0.5.0-beta.2
npx --no-install bronto-layout doctor --verify-launch

    Expected: launch-verified. Browser did not start?

  2. Check the healthy page

    The approved relationship holds. The check exits 0.

    npx --no-install bronto-layout check \
  --spec node_modules/@ponchia/layout/examples/portfolio-alignment.json \
  --url node_modules/@ponchia/layout/examples/portfolio-alignment-healthy.html

    EXIT 0 11 passed · 0 failed · 1 skipped. Actual CLI output

  3. Catch the intentional break

    Only the desktop/tablet alignment fails. A failure here is the expected result.

    npx --no-install bronto-layout check \
  --spec node_modules/@ponchia/layout/examples/portfolio-alignment.json \
  --url node_modules/@ponchia/layout/examples/portfolio-alignment-broken.html

    EXIT 1 9 passed · 2 failed · 1 skipped. Actual CLI output

If doctor cannot launch Chrome

Install Chrome or Chromium, then retry. Select a known installation with --chrome /path/to/chrome or CHROME_PATH. Finding an executable alone does not prove it can launch. Resolve local sandbox or permission errors before checking your site; do not bypass the sandbox for untrusted pages.

03 / Bring your own intent

Then check your own page.

Inspect → approve → enforce

Start your local app. Audit for measured overflow and broken visible images. Create a contract, edit stable selectors and rules, then check it in CI.

Suggestions are reviewable drafts. A clean audit cannot infer which relationships your design needs.

Follow the first-run guide ↗
# Your app must already be running.
npx --no-install bronto-layout audit \
  --url http://localhost:5173 \
  --widths 320,375,768,1280 --json --compact

npx --no-install bronto-layout init \
  --url http://localhost:5173 --out bronto-layout.json

# Edit selectors and rules before enforcing.
npx --no-install bronto-layout validate \
  --spec bronto-layout.json
npx --no-install bronto-layout check \
  --spec bronto-layout.json --json

Know the boundary

A contract checks
what you declare.

It does not certify the whole design or repair CSS. This fixture demonstrates one explicit relationship, not real-world detector accuracy or independent adoption.

Exit 0
Observed checks passed, or no verified regression.
Exit 1
A measured violation or regression.
Exit 2
Invalid input, runtime error or unverified evidence.

Chromium-family browsers only. Closed shadow roots, cross-origin frame interiors, canvas/WebGL paint and unobserved states are outside the verified scope. Browser checks sample declared widths.
